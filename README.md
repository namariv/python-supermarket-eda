# python-supermarket-eda
# Анализ продаж супермаркета (EDA) на Python

## О проекте
Этот проект демонстрирует навыки разведочного анализа данных (Exploratory Data Analysis - EDA). Цель — найти инсайты в данных о продажах сети супермаркетов, чтобы помочь бизнесу понять, какие города и категории товаров приносят больше всего выручки.

## Данные
**Источник:** Kaggle (Supermarket Sales Dataset)
**Описание:** Исторические данные о продажах в трех филиалах супермаркета за 3 месяца. Содержит информацию о типе клиента, поле, категории товара, сумме чека и рейтинге.

## Инструменты
*   **Python** (pandas) — для загрузки, очистки, группировки и агрегации данных.
*   **Matplotlib / Seaborn** — для визуализации результатов (построение диаграмм).

## Как запустить
Вы можете открыть файл `analysis.ipynb` прямо на GitHub (он отрендерит код и график) или запустить его в Google Colab.

На основе проведенного анализа данных были выявлены следующие инсайты:
